## Fix 1 — Sanitize Scraped Text (Python Scripts)

**Files:** `tools/fetch_inbox.py`, `tools/refetch_jobs_browser.py`

Add this helper to both scripts (after the `import re` line):

```python
def sanitize_text(text: str) -> str:
    """Strip characters that confuse LLM JSON generation."""
    if not text:
        return text
    text = text.replace('[', '(').replace(']', ')')
    text = text.replace('{', '(').replace('}', ')')
    text = re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]', '', text)
    text = re.sub(r'\n{3,}', '\n\n', text)
    return text.strip()
```

**In `fetch_inbox.py`** (~line 354), apply to the `entry` dict:
```python
entry = {
    'title': sanitize_text(result['title']) if result else 'N/A',
    'company': sanitize_text(result.get('company', 'N/A')) if result else 'N/A',
    'description': sanitize_text(result['description']) if result else 'Could not extract',
    ...
}
```

**In `refetch_jobs_browser.py`** (~line 300), apply to `original_job.update(...)`:
```python
original_job.update({
    'title': sanitize_text(result['title']),
    'company': sanitize_text(result.get('company', 'N/A')),
    'description': sanitize_text(result['description']),
    ...
})
```

**One-time fix:** Also remove the 3 orphan `]` lines in `data/job_evaluations.json` directly (Clearwater Analytics ~line 96, S&P Global ~line 144, Snowflake ~line 241).

### Data Model

**`Jobs`** table (13 rows, one per job):

| Column | Type |
|---|---|
| JobID | Int (index) |
| Title | Text |
| Company | Text |
| SkillMatch | Decimal (0–100) |
| ExperienceLevelMatch | Decimal |
| CompanyFit | Decimal |
| GrowthPotential | Decimal |
| RedFlags | Decimal (lower = better) |
| OverallFit | Decimal |
| FitCategory | Text (high / medium / low) |
| Recommendation | Text |
| ReasonSummary | Text |

**Expanded array tables** (one row per item):
- `JobStrengths(JobID, Strength)` ← from `key_strengths[]`
- `JobGaps(JobID, Gap)` ← from `skill_gaps[]`
- `JobRedFlagsDetail(JobID, RedFlag)` ← from `red_flags_list[]`

**Key DAX measures:**
```dax
Avg Overall Fit = AVERAGE(Jobs[OverallFit])
High Fit Count = COUNTROWS(FILTER(Jobs, Jobs[FitCategory] = "high"))
Adj Fit Score = Jobs[OverallFit] * (1 - Jobs[RedFlags]/200)
```

### Report Pages

| Page | Visuals |
|---|---|
| **Executive Summary** | KPI cards (High Fit Count, Avg Fit), Donut (FitCategory), Ranked table, Slicer |
| **Scoring Comparison** | Clustered bar (5 metrics × 13 jobs, sorted by OverallFit), RedFlags overlay |
| **Decision Matrix** | Scatter (X=SkillMatch, Y=OverallFit, size=GrowthPotential, color=FitCategory), quadrant lines at 75 |
| **Job Detail** | Drill-through from any row; gauge, score bars, strength/gap/red-flag lists |

**Theme:** Dark (`#1E2A3A`) + teal accent (`#00B4D8`), Segoe UI. Conditional formatting: green ≥ 80, amber 60–79, red < 60.
